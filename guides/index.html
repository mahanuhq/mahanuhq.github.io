Mahanu for builders and learners

What is Mahanu?

Mahanu is a home for shared projects: a comic, drawing practice, study circle, band, robotics team, app, family archive, or another pursuit. Start with an idea, invite your circle, make a plan, and build.

One rule defines what belongs: a project helps its members get better at a shared pursuit. This includes science, art, craft, and sport.

How it works

On desktop, your project lives on a disk you choose as open-format files. A server project lives on storage rented from Mahanu and can later be copied to a desktop. Mahanu adds backup, collaboration, history, calendars, checklists, and tables without locking the work into one app.

The promise

Your project should remain useful even if Mahanu disappears.

On desktop, the current work is readable Markdown and standard media on a disk you choose. You can use normal tools on those files. Mahanu adds collaboration, history, recovery, and useful views without turning your work into a proprietary export format.

Projects can start on a desktop or Mahanu server. Mobile creation initially uses a server project. You may add full project copies on other supported devices without creating a different project.

How working together should feel

  • Ordinary text merges across project copies, including edits made outside Mahanu.
  • Work continues offline and catches up after reconnecting.
  • History uses plain words: version, restore, conflict, and needs review.
  • Calendars, checklists, tables, and other views sit over the same project data.
  • A starter gives you a useful first step instead of an empty workspace.
  • An invoked assistant may propose changes, but cannot quietly act for you.

Mahanu shows where work is actually safe: on this device, in a readable file, received by another device, committed on the server, or included in the server backup. It does not hide these differences behind one “synced” label.

Private work and public work

Projects are private to their members by default. Publishing choices are separate:

  1. Show the project name, tagline, and purpose in Explore.
  2. Publish selected files or media.
  3. Let Mahanu use unencrypted server data to make anonymous templates, examples, and guidance for similar projects.

Mahanu can read unencrypted project data stored on its servers to operate the service and enforce the Code of Conduct. Mahanu cannot read passphrase-protected files. These files use clear versions and branches instead of live text merging.

A network of projects, not people

Mahanu is meant to help people find pursuits, examples, and reusable ways of working. It is not a feed or a popularity contest. There are no likes, follower counts, behavioral ads, or infinite scroll.

Public work can become a portfolio built by doing. Starters and published methods can help another group begin, with attribution to their source. The work remains the center; members do not become content.
