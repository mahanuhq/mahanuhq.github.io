Mahanu FAQ

Work in progress.
Mahanu is pre-launch. This page describes the intended product. Some features below are not built yet.

Basics

What is Mahanu?
A workspace for a small group building or learning something together. A project holds the work, not an audience or social feed. → Vision
Who is it for?
Builders, learners, families, clubs, study groups, artists, makers, coaches, and solo users who may invite others later. → For builders and learners
What works today?
An experimental desktop app and two-device LAN prototype. The durable hosted server, web and mobile apps, protected files, and public-service flows are not shipped.
How is it different from a shared drive or a document with chat?
It puts a focused project, readable files you own, collaboration with history, and a small public surface in one place—without feeds or engagement loops. → Why Mahanu
Why the name?
“Maha” means big; “anu” means small. Large goals start with small steps.
What does Mahanu believe?
Mahanu values truth, beauty, persistence, shared learning, and projects that create value without harming others. → Philosophy · Pre-launch legal and trust documents

Files, sync, and backup

Do I own my work?
You keep the rights you already hold. Desktop projects use readable Markdown and standard media files. The software is MIT-licensed. → If Mahanu disappears
Can I edit files in another app?
That is the goal. Mahanu should notice an external edit and merge it with app edits without silently overwriting either one.
Do I need to install anything?
Not to start. The web app supports common work, but not every desktop feature. Desktop is the strongest app and writes project files to a disk you choose.
Is my work uploaded to Mahanu’s servers?
Only if you choose server sync or start on the web or mobile. A desktop-only project stays on its local disk. A web or mobile project starts on a Mahanu server disk and can be downloaded as a readable folder.
Can two laptops work without a Mahanu server?
Yes. Desktop devices on the same LAN can pair and share a project directly. Server sync is optional.
Is server sync a backup?
Server sync keeps a full project copy and history on Mahanu’s server. It is a synced backup, but mistakes and deletions may also sync. Saved versions let users recover earlier states.
Does it work offline?
Desktop does. Web and mobile are designed to queue supported offline work and catch up later.
What if two people edit at once?
Ordinary text is designed to merge. A small passphrase-protected file is saved as whole-file versions; concurrent edits become branches that a person resolves.
What if Mahanu closes?
You keep readable copies already on your desktop or in a downloaded folder. See If Mahanu disappears.

Privacy and access

What is public?
Nothing by default. You may show the project name, tagline, and purpose in Explore. Publishing selected files is a separate action. → Safety and privacy choices
Why have Explore?
To help people find projects, examples, and shared pursuits—not personalities. Explore is opt-in and has no likes, followers, or endless feed.
What can Mahanu read?
Mahanu can read unencrypted project data stored on Mahanu servers. It uses that access to run the service and enforce the Code of Conduct. A separate choice allows read-only use to create support material for the project and generic, unattributed templates, examples, research, and guidance. This choice starts on at server creation or first sync. Owners may change it later; the change affects only future use. → Privacy Notice
What is a protected file?
A planned small-file feature. The file is encrypted with a passphrase entered on the user's device. Mahanu cannot recover the passphrase or read the file. Members share the passphrase outside Mahanu; losing it can make the file unrecoverable. The user must confirm that protected content still follows the Code of Conduct. Large protected files and protected media are not supported initially. → Safety and privacy choices
How does someone join?
A Mahanu server account requires a project-independent account invitation. Joining a server project requires a separate project invitation. On a LAN, devices pair first, then the person accepts a separate project invitation. No one joins automatically. → Safety and access
Can a removed member keep old copies?
Yes. Removal stops future project traffic; it cannot erase files or keys already copied. → Safety and access
Who owns what I publish, and what if someone copies it?
You keep your rights. A project may set a content licence. The draft policy defines a copyright-notice process. → Copyright and IP

Children, assistants, and public features

Can a parent and child use Mahanu?
The first pilot uses guardian-operated devices and no independent child account. Supervised accounts require product, privacy, recovery, deletion, and legal review before release. → Safety · Guardian Addendum
Does Mahanu have an AI assistant?
An assistant is planned. It must be invoked by a member, propose limited project changes, and wait for confirmation. It is not required for the first collaboration release. → Safety
Are Explore, public join requests, sponsorships, and showcases live?
No. They need reporting, moderation, privacy, and operational controls first. → Safety · Advertising, sponsorship, and support

Service and rights

What does it cost?
Pricing for hosted Mahanu is not final. The software remains free and open source.
Does Mahanu sell data or show ads?
No. Mahanu does not sell project or member data or run behavioural advertising. Children, signed-out visitors, and user-created project pages see no ads. Signed-in adults may later see clearly labelled, contextual commercial content on Mahanu’s Explore, search, or support pages. → Advertising, sponsorship, and support
How do I report something or appeal a decision?
These processes are designed but not yet active. → Reporting and Appeals
How do I delete my project or account?
The deletion process is designed but not yet active. Copies already held by other project members cannot be recalled. → Retention and Deletion
Who else processes my data?
Mahanu will list the providers it uses to run the hosted service. A provider you choose yourself follows its own terms. → Subprocessor Register
Where are the full terms and privacy details?
Both are pre-launch drafts and are not yet in effect. → Terms · Privacy
