A Rounded Life

A draft project — the card and first plan; working docs start with the project.

Most journals record whatever was loudest that day, which means a year of entries can be almost entirely about work and you'd never know until you read them back. This one is deliberately shaped: a small set of standing dimensions — body, mind, people, craft, money, service — so the empty column is as visible as the full one.

Not a habit tracker and not a scoreboard. The aim is noticing, and the only real failure mode is turning a life into a dashboard.

First plan

0 of 6 done
  • Name the dimensions, once, and resist adding more — six is already generous
  • Daily entry: short, prose, whichever dimensions actually moved. Blank is a legitimate answer
  • A weekly look back — what got attention, what didn't, and whether that was a choice
  • Seasonal review: three months read end to end, which is where the pattern actually shows
  • A one-line "what mattered" per month — the entries worth keeping when the rest is noise
  • Rule: no streaks, no scores, no guilt mechanics. A missed week is data, not a failure

Open questions

  • Is this private-by-default forever, or is there a version a partner or a close friend reads?
  • Do the dimensions stay fixed for life, or get re-cut every few years as the life changes shape?

Status

Draft — the dimensions are the whole design decision; everything else follows from them.
