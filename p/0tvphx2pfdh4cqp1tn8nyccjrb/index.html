Science Club Volunteers

A draft project — the card and first plan; working docs start with the project.

The club runs on people who show up on Saturdays for free. That works until one of them can't, and then it works badly — a session cancelled by WhatsApp at 8am, or the same two adults quietly covering everything until they burn out and the club dies with them.

This is the unglamorous half of a club, kept in one place: who's on, who's trained, who's owed a break, and what happens when someone can't make it.

First plan

0 of 6 done
  • Roster: sessions ahead, each with a lead and a second, and the gaps visible rather than discovered
  • Volunteer pages: what each person is comfortable running, what they'd like to learn, when they're unavailable
  • Cover protocol — one place to raise a gap and one place to claim it, so a swap doesn't need six messages
  • Session kits: the equipment list and the run sheet, so a substitute can take a session they've never taught
  • Load ledger: sessions run per person per term, because "who's doing too much" should be a number, not a feeling
  • Safeguarding basics — who's cleared to work with the kids, and when that was last checked

Open questions

  • Where's the line between a rota and a rulebook? Volunteers leave when it starts feeling like a job.
  • Does the load ledger get shared with everyone, or only with whoever runs the club?

Status

Draft — the roster and the cover protocol first; everything else is optional until those two work.
