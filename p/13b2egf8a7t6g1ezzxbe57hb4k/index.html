Mushrooms of the Ghats

A draft project — the card and first plan; working docs start with the project.

The monsoon Ghats put up more fungi in six weeks than most people see in a lifetime, and almost none of it is documented for this region — the field guides are European and the lookalikes they warn about are not the lookalikes here. This project builds the local record: what comes up, where, after which rains, and how to be sure.

Edibility is the last chapter, not the first. A species earns a recipe only after it has been identified confidently across more than one season, and the rule that governs the whole project is the boring one: unsure means not eaten, no exceptions, no "probably".

First plan

0 of 6 done
  • Find log: photograph in place — cap, gills, stem, base, substrate — before anything is picked
  • One doc per species: habitat, season, spore print, the features that confirm it, and the features that rule out its lookalikes
  • A lookalike register kept deliberately: the dangerous pairs of the Ghats, written up before either is collected
  • Seasonal calendar — what appears after the first rains versus deep monsoon versus the retreat
  • Recipes, only for species cleared twice in different seasons and by two people
  • Rule, above everything: unsure is inedible. A project note is not a clearance.

Open questions

  • Who counts as a second opinion — is there a mycologist or a forager we can check identifications against?
  • Do we publish location data at all? Precise spots invite stripping; vague spots make the record useless.

Status

Draft — the lookalike register comes before the first collection, not after.
